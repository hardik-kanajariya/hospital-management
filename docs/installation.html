Installation Guide

Complete step-by-step guide to install and configure MedCare Rural Hospital Management System.

Quick Start (5 Minutes)

Quick Setup: Get up and running in just 5 minutes with these commands.

Step 1: Download and Extract

# Download the package from your purchase # Extract to your desired location unzip medcare-rural-v1.0.0.zip cd medcare-rural

Step 2: Install Dependencies

# Install all required packages npm install # This will take 2-3 minutes depending on your internet speed

Step 3: Start the Application

# Start the development server npm run dev # Your application will be available at: # http://localhost:5173
That's it! Your hospital management system is now running. Open http://localhost:5173 in your browser.

Detailed Installation

Prerequisites

Before installing MedCare Rural, ensure you have the following installed:

Install Node.js

# Download Node.js from https://nodejs.org/ # Or use a package manager: # Windows (using Chocolatey) choco install nodejs # macOS (using Homebrew) brew install node # Ubuntu/Debian curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash - sudo apt-get install -y nodejs # Verify installation node --version npm --version

Install Git (Optional)

# Windows choco install git # macOS brew install git # Ubuntu/Debian sudo apt-get install git # Verify installation git --version

Installation Process

Method 1: Direct Download

  1. Download the package from your purchase
  2. Extract the ZIP file to your desired location
  3. Open terminal/command prompt in the extracted folder
  4. Follow the commands in the Quick Start section

Method 2: Git Clone (If provided)

# Clone the repository (if you have access) git clone https://github.com/yourcompany/medcare-rural.git cd medcare-rural # Install dependencies npm install # Start the application npm run dev

Verification

After installation, verify everything is working correctly:

# Check if the server is running curl http://localhost:5173 # You should see the MedCare Rural application

Docker Setup

Docker Option: For easier deployment and production use, we provide Docker support.

Prerequisites

  • Docker Desktop (Windows/Mac) or Docker Engine (Linux)
  • Docker Compose (usually included with Docker Desktop)

Using Docker Compose

# The project includes a docker-compose.yml file # Simply run: docker-compose up -d # This will: # 1. Build the application image # 2. Start the application container # 3. Set up any required databases # 4. Configure networking # Check if containers are running docker-compose ps # View logs docker-compose logs -f

Manual Docker Build

# Build the Docker image docker build -t medcare-rural . # Run the container docker run -d \ --name hospital-system \ -p 80:80 \ -v $(pwd)/data:/app/data \ medcare-rural # Check if container is running docker ps # Access the application at http://localhost

Docker Environment Variables

# Create a .env file for Docker # docker-compose will automatically use it # Or pass environment variables directly docker run -d \ --name hospital-system \ -p 80:80 \ -e VITE_APP_NAME="My Hospital" \ -e VITE_APP_URL="https://myhospital.com" \ medcare-rural

Production Deployment

Build for Production

# Create production build npm run build # This creates a 'dist' folder with optimized files # Serve the dist folder with any web server

Web Server Configuration

Nginx Configuration

server { listen 80; server_name yourhospital.com; root /var/www/medcare-rural/dist; index index.html; # Handle client-side routing location / { try_files $uri $uri/ /index.html; } # Cache static assets location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ { expires 1y; add_header Cache-Control "public, immutable"; } # Security headers add_header X-Frame-Options "SAMEORIGIN"; add_header X-Content-Type-Options "nosniff"; add_header X-XSS-Protection "1; mode=block"; }

Apache Configuration

<VirtualHost *:80> ServerName yourhospital.com DocumentRoot /var/www/medcare-rural/dist # Handle client-side routing <Directory "/var/www/medcare-rural/dist"> RewriteEngine On RewriteBase / RewriteRule ^index\.html$ - [L] RewriteCond %{REQUEST_FILENAME} !-f RewriteCond %{REQUEST_FILENAME} !-d RewriteRule . /index.html [L] </Directory> # Cache static assets <FilesMatch "\.(js|css|png|jpg|jpeg|gif|ico|svg)$"> ExpiresActive On ExpiresDefault "access plus 1 year" </FilesMatch> </VirtualHost>

SSL/HTTPS Setup

# Using Let's Encrypt with Certbot sudo apt install certbot python3-certbot-nginx # Get SSL certificate sudo certbot --nginx -d yourhospital.com # Auto-renewal sudo crontab -e # Add this line: 0 12 * * * /usr/bin/certbot renew --quiet

Troubleshooting

Common Installation Issues

Issue: npm install fails with permission errors
Solution: Use sudo (Linux/Mac) or run as administrator (Windows)
# Linux/Mac sudo npm install # Windows (run Command Prompt as Administrator) npm install # Alternative: Use npx instead npx create-react-app --template medcare-rural
Issue: Port 5173 already in use
Solution: Kill existing process or use different port
# Find process using port 5173 lsof -i :5173 # Mac/Linux netstat -ano | findstr :5173 # Windows # Kill the process kill -9 PID # Mac/Linux taskkill /PID PID /F # Windows # Or use different port npm run dev -- --port 3000
Issue: Module not found errors
Solution: Clear cache and reinstall dependencies
# Clear npm cache npm cache clean --force # Delete node_modules and package-lock.json rm -rf node_modules package-lock.json # Reinstall dependencies npm install

Runtime Issues

Issue: White screen after loading
Solution: Check browser console for JavaScript errors
  • Open browser developer tools (F12)
  • Check Console tab for errors
  • Verify all environment variables are set correctly
  • Clear browser cache and hard refresh (Ctrl+F5)
Issue: Data not persisting between sessions
Solution: Check browser storage settings
  • Ensure localStorage is enabled in browser
  • Check if browser is in private/incognito mode
  • Verify storage quota is not exceeded

Getting Help

First Time Setup

Initial Access

After successful installation, access your system:

  1. Open your browser and navigate to http://localhost:5173
  2. You'll see the MedCare Rural landing page
  3. Click "Access Hospital System" to open the login page
  4. Use the default super admin credentials to log in
Default Super Admin Credentials:
Email: admin@hospital.com
Password: admin123
Security Notice: Change the default password immediately after first login!

Basic Configuration Steps

  1. Change Admin Password: Go to User Management > Edit Profile
  2. Hospital Information: Set up your hospital details
  3. Create User Accounts: Add staff members with appropriate roles
  4. Configure Departments: Set up your hospital departments
  5. Billing Setup: Configure tax rates and payment methods
  6. Notification Settings: Set up SMS/Email configurations
