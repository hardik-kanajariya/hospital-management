API Reference

Complete API documentation for MedCare Rural Hospital Management System integration.

API Overview

Base URL: All API requests should be made to https://your-domain.com/api/v1

Core Features

  • RESTful Design: Standard HTTP methods (GET, POST, PUT, DELETE)
  • JSON Format: All requests and responses use JSON
  • Authentication: JWT-based authentication system
  • Rate Limiting: Built-in rate limiting for API security
  • Versioning: API versioning for backward compatibility
  • Error Handling: Standardized error responses

Request Headers

Content-Type: application/json Authorization: Bearer {jwt_token} Accept: application/json X-Requested-With: XMLHttpRequest

Response Format

All API responses follow this standard format:

{ "success": true, "message": "Operation completed successfully", "data": { // Response data here }, "meta": { "pagination": { "current_page": 1, "per_page": 20, "total": 100, "last_page": 5 } } }

Authentication

Login

Authenticate user and get access token.

POST /api/v1/auth/login Request Body: { "email": "doctor@hospital.com", "password": "password123", "remember_me": false } Response: { "success": true, "message": "Login successful", "data": { "token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...", "token_type": "Bearer", "expires_in": 3600, "user": { "id": 1, "name": "Dr. John Smith", "email": "doctor@hospital.com", "role": "doctor", "hospital_id": 1, "permissions": ["patients.read", "patients.write"], "avatar": "/avatars/doctor1.jpg" } } }

Refresh Token

POST /api/v1/auth/refresh Headers: Authorization: Bearer {current_token} Response: { "success": true, "data": { "token": "new_jwt_token_here", "expires_in": 3600 } }

Logout

POST /api/v1/auth/logout Headers: Authorization: Bearer {jwt_token} Response: { "success": true, "message": "Successfully logged out" }

Patients API

Get All Patients

GET /api/v1/patients Query Parameters: - page: Page number (default: 1) - per_page: Items per page (default: 20, max: 100) - search: Search by name, phone, or patient ID - age_min: Minimum age filter - age_max: Maximum age filter - gender: Filter by gender (male, female, other) - department: Filter by department - status: Filter by status (active, inactive) Example: GET /api/v1/patients?page=1&per_page=20&search=John&gender=male Response: { "success": true, "data": [ { "id": 1, "patient_id": "PAT001", "name": "John Smith", "age": 45, "gender": "male", "phone": "+1234567890", "email": "john@email.com", "address": "123 Main St, City", "date_of_birth": "1978-05-15", "blood_group": "A+", "emergency_contact": { "name": "Jane Smith", "relationship": "wife", "phone": "+1234567891" }, "medical_history": [ { "condition": "Hypertension", "diagnosed_date": "2020-01-15", "status": "active" } ], "vaccinations": [ { "vaccine": "COVID-19", "date": "2021-06-15", "dose": "2nd dose" } ], "insurance": { "provider": "Health Insurance Co.", "policy_number": "POL123456", "valid_until": "2024-12-31" }, "created_at": "2024-01-01T10:00:00Z", "updated_at": "2024-01-01T10:00:00Z" } ], "meta": { "pagination": { "current_page": 1, "per_page": 20, "total": 150, "last_page": 8 } } }

Get Single Patient

GET /api/v1/patients/{id} Response: { "success": true, "data": { // Full patient object with all details "id": 1, "patient_id": "PAT001", // ... all patient fields "appointments": [ // Recent appointments ], "medical_records": [ // Recent medical records ], "billing_history": [ // Recent billing records ] } }

Create Patient

POST /api/v1/patients Request Body: { "name": "John Smith", "age": 45, "gender": "male", "phone": "+1234567890", "email": "john@email.com", "address": "123 Main St, City", "date_of_birth": "1978-05-15", "blood_group": "A+", "emergency_contact": { "name": "Jane Smith", "relationship": "wife", "phone": "+1234567891" }, "medical_history": [ { "condition": "Hypertension", "diagnosed_date": "2020-01-15", "notes": "Controlled with medication" } ], "insurance": { "provider": "Health Insurance Co.", "policy_number": "POL123456", "valid_until": "2024-12-31" } } Response: { "success": true, "message": "Patient created successfully", "data": { "id": 152, "patient_id": "PAT152", // ... created patient object } }

Update Patient

PUT /api/v1/patients/{id} Request Body: { "name": "John Smith Jr.", "phone": "+1234567899", "address": "456 New St, City" // ... other fields to update } Response: { "success": true, "message": "Patient updated successfully", "data": { // Updated patient object } }

Delete Patient

DELETE /api/v1/patients/{id} Response: { "success": true, "message": "Patient deleted successfully" }

Appointments API

Get Appointments

GET /api/v1/appointments Query Parameters: - date: Filter by date (YYYY-MM-DD) - date_from: Start date range - date_to: End date range - doctor_id: Filter by doctor - patient_id: Filter by patient - status: Filter by status (scheduled, completed, cancelled, no-show) - department: Filter by department Example: GET /api/v1/appointments?date=2024-01-15&doctor_id=2 Response: { "success": true, "data": [ { "id": 1, "appointment_id": "APT001", "patient": { "id": 1, "name": "John Smith", "patient_id": "PAT001", "phone": "+1234567890" }, "doctor": { "id": 2, "name": "Dr. Jane Doe", "specialization": "Cardiology", "department": "Cardiology" }, "appointment_date": "2024-01-15", "appointment_time": "10:30:00", "duration": 30, "status": "scheduled", "type": "consultation", "notes": "Regular checkup", "symptoms": ["chest pain", "shortness of breath"], "created_at": "2024-01-10T14:30:00Z", "updated_at": "2024-01-10T14:30:00Z" } ] }

Create Appointment

POST /api/v1/appointments Request Body: { "patient_id": 1, "doctor_id": 2, "appointment_date": "2024-01-20", "appointment_time": "14:30:00", "duration": 30, "type": "consultation", "notes": "Follow-up appointment", "symptoms": ["headache", "fever"] } Response: { "success": true, "message": "Appointment scheduled successfully", "data": { "id": 25, "appointment_id": "APT025", // ... appointment details } }

Update Appointment

PUT /api/v1/appointments/{id} Request Body: { "appointment_date": "2024-01-22", "appointment_time": "15:00:00", "status": "rescheduled", "notes": "Patient requested reschedule" } Response: { "success": true, "message": "Appointment updated successfully", "data": { // Updated appointment object } }

Cancel Appointment

PATCH /api/v1/appointments/{id}/cancel Request Body: { "cancellation_reason": "Patient unable to attend", "cancelled_by": "patient" } Response: { "success": true, "message": "Appointment cancelled successfully" }

Inventory API

Get Inventory Items

GET /api/v1/inventory Query Parameters: - category: Filter by category (medicine, equipment, supplies) - low_stock: Show only low stock items (true/false) - expired: Show expired items (true/false) - search: Search by name or SKU Response: { "success": true, "data": [ { "id": 1, "sku": "MED001", "name": "Paracetamol 500mg", "category": "medicine", "manufacturer": "Pharma Co.", "batch_number": "BATCH001", "expiry_date": "2025-06-30", "current_stock": 150, "minimum_stock": 50, "maximum_stock": 500, "unit_price": 0.50, "supplier": { "id": 1, "name": "Medical Supplies Ltd.", "contact": "+1234567890" }, "location": "Pharmacy - Shelf A1", "status": "active", "last_updated": "2024-01-15T09:00:00Z" } ] }

Error Handling

Error Response Format

{ "success": false, "message": "Validation error", "errors": { "email": ["The email field is required"], "phone": ["The phone number format is invalid"] }, "error_code": "VALIDATION_ERROR", "timestamp": "2024-01-15T10:30:00Z" }

HTTP Status Codes

Code Meaning Description
200 OK Request successful
201 Created Resource created successfully
400 Bad Request Invalid request data
401 Unauthorized Authentication required
403 Forbidden Insufficient permissions
404 Not Found Resource not found
422 Unprocessable Entity Validation errors
429 Too Many Requests Rate limit exceeded
500 Internal Server Error Server error
