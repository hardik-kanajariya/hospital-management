Customization Guide

Complete guide to customizing MedCare Rural for your specific hospital needs.

Customization Overview

Flexible Architecture: MedCare Rural is built with customization in mind, allowing you to adapt the system to your specific requirements.

What Can Be Customized

  • User Interface: Colors, fonts, layouts, and components
  • Forms and Fields: Add custom fields and validation rules
  • Reports: Create custom reports and dashboards
  • Workflows: Modify business logic and processes
  • Integrations: Connect with external systems
  • Modules: Add new functionality or modify existing
  • Permissions: Create custom user roles and access levels
  • Notifications: Custom email and SMS templates

Theming & Branding

Hospital Branding

Customize the visual appearance to match your hospital's brand identity.

Logo and Images

// Update hospital logo // Place your logo file in src/assets/images/ import hospitalLogo from '@/assets/images/hospital-logo.png' // Update in App.tsx header section <div className="logo"> <img src={hospitalLogo} alt="Hospital Logo" className="h-10 w-auto" /> <span>Your Hospital Name</span> </div>

Color Scheme

Modify the color palette in src/index.css:

:root { /* Primary brand color - your hospital's main color */ --primary: oklch(0.6 0.12 240); /* Professional blue */ --primary-foreground: oklch(1 0 0); /* Secondary colors for UI elements */ --secondary: oklch(0.96 0 0); --secondary-foreground: oklch(0.2 0 0); /* Accent color for highlights and CTAs */ --accent: oklch(0.7 0.15 140); /* Success green */ --accent-foreground: oklch(1 0 0); /* Custom hospital colors */ --hospital-primary: oklch(0.55 0.15 210); /* Your primary color */ --hospital-secondary: oklch(0.65 0.12 160); /* Your secondary color */ --hospital-accent: oklch(0.75 0.18 45); /* Your accent color */ } /* Apply custom colors */ @theme { --color-hospital-primary: var(--hospital-primary); --color-hospital-secondary: var(--hospital-secondary); --color-hospital-accent: var(--hospital-accent); }

Typography

Update fonts in index.html and index.css:

<!-- In index.html head section --> <link href="https://fonts.googleapis.com/css2?family=Roboto:wght@300;400;500;600;700&display=swap" rel="stylesheet"> /* In index.css */ body { font-family: 'Roboto', 'Inter', sans-serif; } /* Custom font classes */ .hospital-heading { font-family: 'Your Custom Font', serif; font-weight: 600; }

Billing Workflow Customization

// Custom billing process for rural hospitals const ruralBillingWorkflow = { // Automatic government scheme detection detectSchemes: (patient) => { const schemes = []; if (patient.ayushman_bharat_id) { schemes.push({ name: 'Ayushman Bharat', coverage: 500000, applicable_services: ['consultation', 'surgery', 'medicines'] }); } if (patient.bpl_card) { schemes.push({ name: 'BPL Scheme', discount: 80, applicable_services: ['consultation', 'basic_medicines'] }); } return schemes; }, // Custom pricing for rural areas calculateCharges: (services, patient) => { let total = 0; const schemes = detectSchemes(patient); services.forEach(service => { let charge = service.base_price; // Apply rural pricing if (patient.location_type === 'rural') { charge *= 0.8; // 20% discount for rural patients } // Apply scheme benefits schemes.forEach(scheme => { if (scheme.applicable_services.includes(service.type)) { if (scheme.coverage && total + charge <= scheme.coverage) { charge = 0; // Covered by scheme } else if (scheme.discount) { charge *= (1 - scheme.discount / 100); } } }); total += charge; }); return total; } }

Custom Reports

Creating Custom Report Components

// Custom report for rural health statistics import React from 'react'; import { usePatientApi, useAppointmentApi } from '@/hooks/useApiHooks'; const RuralHealthReport = () => { const { patients } = usePatientApi(); const { appointments } = useAppointmentApi(); // Calculate rural-specific metrics const ruralPatients = patients.filter(p => p.location_type === 'rural'); const chronicDiseases = ruralPatients.filter(p => p.medical_history?.some(h => h.condition === 'Diabetes' || h.condition === 'Hypertension') ); const maternalHealth = appointments.filter(a => a.department === 'Gynecology' && a.patient.age >= 15 && a.patient.age <= 45 ); return ( <div className="space-y-6"> <h2 className="text-2xl font-bold">Rural Health Statistics</h2> {/* Demographics */} <Card> <CardHeader> <CardTitle>Patient Demographics</CardTitle> </CardHeader> <CardContent> <div className="grid grid-cols-2 md:grid-cols-4 gap-4"> <StatCard title="Total Rural Patients" value={ruralPatients.length} /> <StatCard title="Chronic Disease Patients" value={chronicDiseases.length} /> <StatCard title="Maternal Health Visits" value={maternalHealth.length} /> <StatCard title="Vaccination Coverage" value="85%" /> </div> </CardContent> </Card> {/* Disease Prevalence */} <Card> <CardHeader> <CardTitle>Common Diseases in Rural Area</CardTitle> </CardHeader> <CardContent> <DiseaseChart data={calculateDiseasePrevalence(ruralPatients)} /> </CardContent> </Card> </div> ); }; // Helper function const calculateDiseasePrevalence = (patients) => { const diseases = {}; patients.forEach(patient => { patient.medical_history?.forEach(condition => { diseases[condition.condition] = (diseases[condition.condition] || 0) + 1; }); }); return Object.entries(diseases).map(([disease, count]) => ({ disease, count, percentage: ((count / patients.length) * 100).toFixed(1) })); };

// Razorpay integration for online payments import { loadScript } from '@/utils/loadScript'; const PaymentIntegration = { async processPayment(amount, patientData, billId) { // Load Razorpay script const res = await loadScript('https://checkout.razorpay.com/v1/checkout.js'); if (!res) { throw new Error('Failed to load payment gateway'); } const options = { key: process.env.VITE_RAZORPAY_KEY, amount: amount * 100, // Amount in paise currency: 'INR', name: 'Your Hospital Name', description: `Medical Bill Payment - ${billId}`, image: '/hospital-logo.png', handler: function (response) { // Payment successful updatePaymentStatus(billId, response.razorpay_payment_id); sendPaymentConfirmation(patientData.phone, response.razorpay_payment_id); }, prefill: { name: patientData.name, email: patientData.email, contact: patientData.phone }, theme: { color: '#3b82f6' } }; const paymentObject = new window.Razorpay(options); paymentObject.open(); } };

Best Practices

Code Organization

  • Modular Structure: Keep customizations in separate modules
  • Configuration Files: Use dedicated config files for easy maintenance
  • Environment Variables: Store sensitive data in environment variables
  • Version Control: Track all customizations in version control
  • Documentation: Document all custom changes and configurations

Performance Considerations

  • Lazy Loading: Load custom components only when needed
  • Caching: Implement appropriate caching for custom data
  • Database Optimization: Index custom fields properly
  • Asset Optimization: Optimize custom images and assets
  • Bundle Size: Monitor bundle size when adding custom features

Security Guidelines

  • Input Validation: Validate all custom form inputs
  • Access Control: Implement proper permissions for custom features
  • Data Encryption: Encrypt sensitive custom data
  • Audit Trails: Log custom operations for compliance
  • Regular Updates: Keep custom integrations updated

Maintenance Guidelines

  • Backup Strategy: Regular backups before major customizations
  • Testing: Thoroughly test all customizations
  • Staging Environment: Test customizations in staging first
  • Rollback Plan: Have a rollback strategy for failed customizations
  • Documentation: Maintain detailed customization documentation
