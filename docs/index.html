System Overview

Premium Software: This is a commercial hospital management system designed for rural healthcare facilities. Unauthorized use without a valid license is prohibited.

MedCare Rural is a comprehensive hospital management system specifically designed for rural hospitals and small healthcare facilities. Built with modern web technologies and an offline-first architecture, it provides reliable healthcare management even in areas with limited internet connectivity.

Key Highlights

  • Offline-First Architecture: Works seamlessly without internet connectivity
  • Role-Based Access Control: Secure access for different staff roles
  • Comprehensive Patient Management: Complete patient records with medical history
  • Integrated Billing System: Advanced billing with insurance claim processing
  • Inventory Management: Track medicines and medical supplies
  • Laboratory Management: Order tests and track results
  • Bed Management: Monitor bed occupancy and room assignments
  • Doctor Scheduling: Manage doctor availability and shifts

Target Audience

This system is designed for:

  • Small to medium rural hospitals (10-100 beds)
  • Community health centers
  • Private clinics and nursing homes
  • Medical practices in remote areas

Features

Patient Management

Complete patient registration, medical history tracking, vaccination records, and chronic condition management with advanced search capabilities.

Appointment Scheduling

Advanced calendar-based appointment booking with doctor availability checking, conflict resolution, and automated reminders via SMS.

Electronic Medical Records

Digital medical records with consultation notes, diagnosis tracking, prescription management, and treatment plan documentation.

Billing & Insurance

Comprehensive billing system with insurance claim processing, payment tracking, automated tax calculations, and financial reporting.

Inventory Management

Track medical supplies, medicines, equipment with low stock alerts, expiry date monitoring, and automated reorder points.

Laboratory Management

Order lab tests, track sample collection, manage results, and generate comprehensive lab reports with reference ranges.

Bed Management

Monitor bed occupancy, room assignments, admission and discharge management with real-time availability tracking.

Doctor Scheduling

Manage doctor availability, shift planning, workload distribution, and consultation scheduling with conflict detection.

Role-Based Access

Secure authentication system with role-based permissions for doctors, nurses, staff, billing managers, and administrators.

Offline Capability

Offline-first architecture with automatic synchronization ensures the system works even without internet connectivity.

Reporting & Analytics

Generate comprehensive reports for patient statistics, financial analysis, inventory status, and operational metrics.

Notification System

Automated SMS and email notifications for appointments, lab results, payment reminders, and critical alerts.

Installation Guide

License Required: This software requires a valid commercial license. Please ensure you have purchased a license before installation.

Step 1: Download and Extract

# Extract the purchased package
unzip medcare-rural-v2.0.zip
cd medcare-rural

# Verify license file
ls -la LICENSE.txt

Step 2: Database Setup

# Install MySQL and create database
mysql -u root -p
CREATE DATABASE medcare_rural;
CREATE USER 'medcare_user'@'localhost' IDENTIFIED BY 'secure_password';
GRANT ALL PRIVILEGES ON medcare_rural.* TO 'medcare_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;

# Import database schema
mysql -u medcare_user -p medcare_rural < database/schema.sql

Step 3: Environment Configuration

# Copy environment template
cp .env.example .env

# Edit configuration
nano .env
Environment Variables: Configure database credentials, JWT secrets, and other settings in the .env file. See the configuration section for detailed instructions.

Step 4: Install Dependencies

# Install Node.js dependencies
npm install

# Install additional database packages
npm install mysql2 idb

Step 5: Build and Start

# Build the application
npm run build

# Start in production mode
npm run start

# Or use PM2 for production
npm install -g pm2
pm2 start ecosystem.config.js

Step 6: Initial Setup

  1. Access the application at http://localhost:3000
  2. Login with default credentials: admin@medcare.local / admin123
  3. Change the default password immediately
  4. Configure hospital settings and create user accounts
  5. Test offline functionality by disconnecting from the internet

Database Reference

Database Schema

The system uses a comprehensive MySQL schema with the following main tables:

Table Purpose Key Fields
users User authentication and roles email, password_hash, role, permissions
patients Patient demographic and medical info patient_id, name, phone, medical_history
appointments Appointment scheduling patient_id, doctor_id, date, time, status
medical_records Electronic medical records patient_id, doctor_id, diagnosis, treatment
billing_records Billing and invoicing patient_id, amount, payment_status, items
inventory_items Medical supplies and medicines name, category, stock, expiry_date
lab_tests Laboratory test management patient_id, test_name, status, results
beds Hospital bed management bed_number, room_type, status, patient_id

Data Relationships

The database maintains referential integrity through foreign key relationships:

  • Patients → Appointments (one-to-many)
  • Doctors → Appointments (one-to-many)
  • Patients → Medical Records (one-to-many)
  • Patients → Billing Records (one-to-many)
  • Patients → Lab Tests (one-to-many)

Backup and Maintenance

# Create database backup
mysqldump -u medcare_user -p medcare_rural > backup_$(date +%Y%m%d).sql

# Optimize database performance
mysql -u medcare_user -p -e "OPTIMIZE TABLE patients, appointments, medical_records;"

# Check database size
mysql -u medcare_user -p -e "
SELECT 
    table_name,
    ROUND(((data_length + index_length) / 1024 / 1024), 2) AS 'Size (MB)'
FROM information_schema.tables 
WHERE table_schema = 'medcare_rural'
ORDER BY (data_length + index_length) DESC;"

API Reference

The system provides a comprehensive REST API for integration with third-party systems.

Authentication

POST /api/auth/login
Content-Type: application/json

{
  "email": "user@hospital.com",
  "password": "password"
}

Response:
{
  "success": true,
  "data": {
    "token": "jwt_token_here",
    "user": {
      "id": "user_id",
      "name": "User Name",
      "role": "doctor",
      "permissions": ["patients", "appointments"]
    }
  }
}

# Get all patients

Troubleshooting

Common Issues

Database Connection Issues

Error: "Database connection refused"

Solution:

  1. Check MySQL service status: sudo systemctl status mysql
  2. Verify database credentials in .env file
  3. Ensure database user has proper permissions
  4. Check firewall settings

Sync Issues

Error: "Data not syncing between devices"

Solution:

  1. Check internet connectivity
  2. Verify API server is running
  3. Clear browser cache and IndexedDB
  4. Check sync queue in browser developer tools

Performance Issues

Issue: Slow loading times

Solution:

  1. Optimize database queries
  2. Enable database indexing
  3. Increase server memory allocation
  4. Use SSD storage for database

Log Files

Check these log files for debugging:

  • Application logs: logs/app.log
  • Database logs: /var/log/mysql/error.log
  • System logs: /var/log/syslog
  • Browser console: Developer Tools → Console
