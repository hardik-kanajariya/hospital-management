Installation Guide

Quick Installation

Follow these simple steps to get MedCare Rural up and running:

Step 1: Download & Extract

# Extract the downloaded file unzip medcare-rural-v1.0.0.zip cd medcare-rural

Step 2: Install Dependencies

# Install required packages npm install # Or using yarn yarn install

Step 3: Configuration

# Copy environment configuration cp .env.example .env # Edit configuration file nano .env

Step 4: Start the Application

# Start development server npm run dev # Or for production npm run build npm run preview
Success! Your hospital management system is now running at http://localhost:5173

Docker Installation Pro

For production deployment, use our Docker setup:

# Build Docker image docker build -t medcare-rural . # Run container docker run -d -p 80:80 --name hospital-system medcare-rural

Configuration Guide

Environment Configuration

Configure the system using environment variables:

# Database Configuration DB_HOST=localhost DB_PORT=5432 DB_NAME=medcare_rural DB_USER=postgres DB_PASSWORD=your_password # Application Settings APP_NAME="MedCare Rural" APP_URL=http://localhost:5173 APP_ENV=production # Security Settings JWT_SECRET=your_jwt_secret_key ENCRYPTION_KEY=your_encryption_key # Email Configuration MAIL_HOST=smtp.gmail.com MAIL_PORT=587 MAIL_USERNAME=your_email@gmail.com MAIL_PASSWORD=your_app_password # SMS Configuration SMS_API_KEY=your_sms_api_key SMS_SENDER_ID=HOSPITAL # Storage Configuration STORAGE_DRIVER=local STORAGE_PATH=/uploads

Hospital Settings

Configure hospital-specific settings through the admin panel:

  • Hospital Information: Name, address, contact details, license number
  • Operating Hours: Working days, shift timings, holiday calendar
  • Departments: Configure hospital departments and specializations
  • Billing Settings: Tax rates, payment methods, insurance providers
  • Notification Settings: SMS/Email templates, reminder schedules
  • Security Settings: Password policies, session timeouts, audit logging

Module Configuration

Enable/disable modules based on hospital requirements:

# Module Configuration ENABLE_PHARMACY=true ENABLE_LABORATORY=true ENABLE_RADIOLOGY=false ENABLE_OPD=true ENABLE_IPD=true ENABLE_EMERGENCY=true ENABLE_AMBULANCE=false

GET /api/patients POST /api/patients PUT /api/patients/{id} DELETE /api/patients/{id} Example Patient Object: { "id": 1, "patient_id": "PAT001", "name": "John Smith", "age": 45, "gender": "male", "phone": "+1234567890", "email": "john@email.com", "address": "123 Main St", "medical_history": [...], "created_at": "2024-01-01T10:00:00Z" }

Troubleshooting

Common Issues

Installation Issues

Problem: npm install fails with permission errors
Solution: Run with administrator privileges or use npx
Problem: Port 5173 already in use
Solution: Kill existing process or use different port: npm run dev -- --port 3000

Database Issues

Problem: Database connection failed
Solution: Check database credentials in .env file and ensure database server is running

Authentication Issues

Problem: Login fails with correct credentials
Solution: Clear browser cache and check JWT secret configuration

Performance Optimization

  • Database: Regular database maintenance and indexing
  • Caching: Enable Redis caching for better performance
  • Images: Compress and optimize uploaded images
  • Network: Use CDN for static assets in production

Security Best Practices

  • Change default passwords immediately
  • Enable HTTPS in production
  • Regular security updates
  • Implement proper backup procedures
  • Monitor access logs regularly
