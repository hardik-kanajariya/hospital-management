System Overview

MedCare Rural is a comprehensive hospital management system specifically designed for rural healthcare facilities in India. Built with modern web technologies and optimized for areas with limited internet connectivity, it provides a complete solution for small to medium-sized hospitals.

Key Highlights

🏥 Rural Healthcare Focus

Designed specifically for the unique needs of rural hospitals with features like offline operation, multilingual support, and simplified workflows.

💾 Offline-First Architecture

Complete functionality without internet connection using IndexedDB for local storage with automatic synchronization when online.

🔐 Role-Based Security

Comprehensive user management with role-based access control for doctors, nurses, billing staff, and administrators.

📊 Complete Healthcare Management

Patient records, appointments, billing, inventory, lab tests, and bed management in one integrated platform.

Installation Guide

Prerequisites Check: Ensure you have the required license and authorization before proceeding with installation.

System Requirements

Server Requirements

  • Node.js 18.0 or higher
  • MySQL 8.0 or higher
  • 4GB RAM minimum (8GB recommended)
  • 100GB storage space
  • Ubuntu 20.04 or CentOS 8

Client Requirements

  • Modern web browser (Chrome, Firefox, Safari)
  • JavaScript enabled
  • Minimum 1024x768 resolution
  • Internet connection (for initial setup)
  • Local network access

Quick Installation

# 1. Extract the application files
tar -xzf medcare-rural-v1.0.tar.gz
cd medcare-rural

# 2. Install dependencies
npm install

# 3. Configure database
cp .env.example .env
# Edit .env file with your database credentials

# 4. Setup database
npm run db:setup

# 5. Start the application
npm run start

# 6. Access at http://localhost:3000

Docker Installation

# Using Docker Compose
docker-compose up -d

# Or build manually
docker build -t medcare-rural .
docker run -p 3000:3000 medcare-rural
Note: Detailed installation instructions and troubleshooting guides are available in the included setup documentation.

Configuration

Environment Variables

# Database Configuration
DB_HOST=localhost
DB_PORT=3306
DB_NAME=medcare_rural
DB_USER=your_username
DB_PASSWORD=your_password

# Application Settings
APP_NAME="MedCare Rural"
APP_URL=http://localhost:3000
APP_ENV=production

# Security
JWT_SECRET=your_secret_key
ENCRYPTION_KEY=your_encryption_key

# SMS Configuration
SMS_API_KEY=your_sms_api_key
SMS_SENDER_ID=HOSPITAL

# Email Configuration
MAIL_HOST=smtp.gmail.com
MAIL_PORT=587
MAIL_USERNAME=your_email
MAIL_PASSWORD=your_password
